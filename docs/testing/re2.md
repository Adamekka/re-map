## Spatial filtering during label placement

The label fitter now builds a local spatial index for each native interior path on a cache miss. It skips a stroke query only when no padded segment bounds can cover the sample; native SVG still decides every possible hit under the [SVG geometry interface](https://www.w3.org/TR/SVG/latest/types.html#InterfaceSVGGeometryElement). Each emitted segment is an independent M-L subpath. Full-stroke-width padding exceeds its square-cap axis extension of at most `width/sqrt(2)`. Buckets span two stroke widths, affecting lookup cost only. Mandatory construction checks require positive finite pixel width, square caps, no vector effect or local transforms, the exact emitted path binding and finite coordinates within `width*2**16`. That bound keeps float32 coordinate rounding comfortably inside the extra padding. Indexes and closures are discarded after calculating the cached label layout.

These checks use explicit test-only visits, not gameplay.
